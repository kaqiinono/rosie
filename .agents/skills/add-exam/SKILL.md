# 添加考试内容

把用户提供的文件转成可管理的完整电子题库草稿，自动关联已有词库，并准备可操作的图片任务。用户不需要编写 JSON、手工选词、查原页位置或手工绑定裁图。KET 和 PET 分别使用各自的草稿模板，其他考试先判断现有契约是否能表达。

## 输入与执行边界

- 接收本地文件路径或附件：试卷、整本题集、扫描页、答案解析、教师材料、音频。利用现有上下文判断书名、版本、卷号和用途；仅在这些影响内容身份或范围的信息无法从文件确定时提问。
- 用户要求整本时覆盖全书中的完整卷和训练内容，按卷/训练包拆分；不要擅自挑第一卷、单题样本或只做阅读部分。只有文件没有可判定的添加范围时，先明确范围。
- 整套添加包含来源映射、电子题目、私有解答、草稿导入、词库自动关联、图片原页与定位任务、已有媒体的准确关联和交付记录。缺失答案、音频、图片审核等必须列出，不伪造、不静默略过。
- 沿用会话已授权的操作范围。用户要求添加到题库时推进草稿入库和必要原页上传；若明确要求仅生成文件，就只写文件。读取文件不代表允许向新的第三方 OCR 服务发送文件。
- 遵守当前 AGENTS.md 和用户执行限制。不要自动安装依赖、启动服务、构建、测试、lint/typecheck 或运行独立检查命令。导入的内置结构校验属于保存契约，不得跳过；若用户连导入命令也禁止，则准备可续跑产物并说明未入库。技能本身不扩大迁移、部署、发布或删除权限。
- 默认交付为未发布草稿。素材齐备不等于来源/解答/媒体审核通过，不直接改成 approved。当前发布已取消审核、媒体、材料族及词条快照就绪门禁，但仍须用户明确要求并通过管理员发布操作；发布成功不代表内容完整或可模考。

## 先读当前契约

从仓库根目录读取：

1. `packages/exams/AGENTS.md`、`packages/exams/source-data/README.md`。
2. `docs/exams-environment-status.md`、`docs/exams-image-workbench.md`，确定实际环境与媒体边界，不从历史完成记录推断本次可用性。题型、图文布局与标题提取另读 [题面与活动编写](references/content-authoring.md)，按需查 `docs/exams-question-rendering.md`、`docs/exams-illustrated-reading-coverage.md`。历史文档包含已被后续改动取代的 demo 状态，以当前类型、实现及最新保存记录为准。
3. `packages/exams/src/types/content.ts`、`questions.ts`、`solutions.ts` 及目标模板；选择一份现有完整卷作为结构参考，不复制它的身份、题文、答案或审核状态。
4. 做来源提取和入库时读 [导入与原页操作](references/import-and-images.md)。数据库操作遵循可用的 Supabase 技能；读取 PDF 时使用可用的 PDF 技能，但用户的禁止测试/检查要求仍然优先。

不要一次加载全部已有题库。按当前卷和当前 Part 阅读来源与对应契约。

## 工作清单

把以下阶段及每卷进度写入本次私有工作目录 `output/exams/<source-id>/<scope>/progress.md`。记录文件身份、已完成页/题组、产物位置和阻塞原因；中断后从记录和导入回执恢复，避免重新提取整本。

### 1. 来源与覆盖范围

- 识别文件版本，计算实际来源 SHA-256；登记 PDF 物理页码（从 1 开始）和独立的印刷页码。逐范围依据原页定位，不假设全书恒定偏移。
- 查找已有 source、content set、material family 和导入回执，区分补充文件、同卷修订、重复扫描与新卷。不要把样本与完整卷重复导入。
- 建立逐卷、逐活动覆盖表：section/Part、页范围、原始题号、计分题、例题、指令原文与题型证据、空位/选项映射、图文关联、答案页、听力稿/口语考官材料、图片、音频。空缺写出原因。已有样例或模板覆盖不代表整本来源已覆盖。
- exam/training 是内容角色，training/reserved 等是使用策略，按实际类型分别设置。保留用于模考的新材料，不在普通练习中提前暴露。

### 2. 真正提取整套内容

- 阅读文档正文并查看必要的扫描页。现有 `extract` 命令只产出页图/文本/恢复清单，**执行它不等于题目电子化完成**。
- 按完整题组提取题干、指令、共享阅读材料、选项池、作答顺序、分值和来源。表格/邮件等使用已支持的结构块；保留上下文，不用整页截图替代本可提取的题文。
- 题号遵循原书；例题单独标识且不计分。共享材料/选项保持整组练习边界。用现有判别联合表达题型，遇到无法表达的题型明确记录并提出最小契约扩展，不丢弃或伪装成其他题型。
- 按原书 Exercise 编写 `activities`，显式保存栏目标题、指令编号、题目引用、图文分区与作答位置。选择、分类、手写和词库展示按当前契约区分；具体字段与坐标规则见 [题面与活动编写](references/content-authoring.md)。不能从下划线、VOCABULARY 标题或答案反推题型。
- 提取答案、解析、听力文本、口语考官稿与评分依据到私有解答。填空保留完整 acceptedAnswerSets 的关联，不把不同答案组合随意拼接。写作/口语用 rubric，不伪造唯一正确答案或官方得分。
- 原文、翻译、AI 补充分别标注来源与 authorship。缺原答案不得靠猜测标成官方答案；原书与答案冲突标 blocked，保留两边准确位置。新提取默认 pending。
- 对照覆盖表逐题核读来源，尤其否定词、选项标签、数字和跨页材料。这是内容编写过程，不运行项目检查脚本。
- 交付逐活动的原页位置与电子题预览入口，供用户并排核对完整题面、图文关系及作答方式；未实际打开预览时保留人工验收待办，不宣称页面已验收。

### 3. 生成作者内容包

每卷/训练包写入 `packages/exams/source-data/<source-id>/<scope>/`：

- `manifest.json`、`content-set.json`、`content.json`、`solutions.private.json`、`source-pages.json`，采用当前导入器读取的准确结构。
- `README.md`：来源范围、题组/题数（计分题与例题分开）、私有解答范围、图片音频缺口、内容冲突和待审核事项。

题库文件不得经客户端 barrel 或学生页面导入。私有原页、提取中间产物、凭据和回执留在私有/忽略目录，不能放入 public。

词库关联按题面原形和变体命中自动建立，使用真实 `word_entries.id` 和词库快照。未命中的词跳过。导入后按 [草稿词库自动关联](references/import-and-images.md#草稿词库自动关联) 完成匹配并记录结果。

### 4. 导入草稿并准备图片任务

自动生成的考试裁图目录由 `saveExamImageCrop` 创建并登记，属于后台托管资源。
添加试卷时无需用户在 `/admin/sync` 的「路径」页添加 `/airosie/exams/<修订哈希>`
（或 `BAIDU_EXAMS_UPLOAD_ROOT` 下的对应目录），也不要额外通过目录 API、SQL 或手动操作重复登记。
按现有裁图上传与绑定流程处理即可；这些自动目录在「路径」列表隐藏是正常行为，不代表缺少配置。
必须保留后台目录记录、已有绑定与访问校验，不删除记录、不绕过鉴权，也不把自动登记步骤从裁图流程移除。
用户提供的外部音频或其他媒体目录仍按既有授权目录和绑定契约处理。

按 [导入与原页操作](references/import-and-images.md) 执行，保存成功回执再报告入库。对每个缺图点完成：

- 可唯一定位的图片槽位，与电子题/选项/材料实际关联。
- 试卷、Part、原题号、PDF/印刷页码和定位说明。
- 私有原页，以及依据原图标出的参考裁切区域；无法可靠确定区域时明确留空，不编造坐标。
- `/admin/exams/images` 所需来源索引，使用户能并排看原题和电子题并提交裁图。只有清单或空槽位不算图片任务准备完成。

用户已明确选择先自动准备图片再审查：对已确定的参考选区，运行 `scripts/prepare-exam-image-crops.mjs --apply --revision <id>` 批量裁切、上传百度并绑定，不让用户逐张裁切提交。跳过已有绑定、已删除任务、无选区或缺原页任务；保存回执，失败沿用原请求续跑。用户在图片任务页查看已绑定成品，只有有问题的图片才重裁替换。自动准备沿用用户授权的选区，不批准整卷内容或发布。音频仅在有真实文件、准确映射及播放程序依据时关联，未审核片段/重复/停顿不宣称可模考。

### 5. 交付与续作

- 更新 source-data 索引及所属内容包说明；只有环境发生实际改变时才更新环境记录。进度按实际回执推进。
- 简洁交付：新增卷/题组/计分题/例题数量，已入库修订，已准备图片任务与原页数量，缺失答案/音频/待裁切项，管理入口。
- 明确区分“文件已生成”“草稿已入库”“词库已关联”“原页已上传”“媒体已绑定”“人工审核/发布/运行验收”。报告已保存的词条数、匹配处数和变体命中数，以及容量限制或未完成的环节。
- 保留请求回执和可续跑位置。身份/版本冲突、权限失败或来源不一致时停止对应写入并报告具体阻塞，不循环重试、不换 ID 绕过冲突。继续不依赖该阻塞的内容编写。

## 资源清理规则

删除图片任务只退役作者任务，并清理无其他活动任务引用的临时原页。**保留电子题、成品题图及其绑定。** 历史作答或当前修订仍引用的成品不能删除；外部手工文件、用户原 PDF 不属于自动清理范围。不要为导入新卷恢复用户已删除的任务；恢复必须有明确意图并遵循现有墓碑/重试流程。
