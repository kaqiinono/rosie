## 2. 题面审核做了什么

| 词或题组 | 编辑处理 |
| --- | --- |
| father、science、interval | father 用亲子、子女、舅舅、外甥四个可区分的释义。science 改用观察和检验想法来说明科学。interval 改考“两次事件之间的时间”，用两次铃声限定语境，旧幕间休息义记录为来源 |
| act、leg、window、article、magazine、pride、recipe、tent、dolphin、poster | 重写过长选项，保留目标义项。例如 leg 用髋与脚、肩与手、头与肩、腕与手指四组身体部位，减少重复阅读 |

| 新题 | 每词单独编写语境、释义和三个干扰项。shoot 使用球赛射门义，objected 按参考表原词形考过去式，patent 通过发明人的排他权与奖项、图纸、账单作区分。[专利义项依据](https://www.wipo.int/en/web/patents) |
| 诊断题 | 沿用 18 道，修订 bad、card 和 view，再从旧主测转入 8 道词族成员题，含 camping、invitation、musician、restriction 等。词族成员作答只进入诊断与错题复盘 |

**读量与猜答线索。** 四个选项按英文词数合计，255 道主测平均 26.5 词，136 道新编平均 22.4 词。主测最长单项 13 词，最长四项合计 40 词。本稿已逐项做文字审读；6–10 岁儿童能否独立理解仍需试读。只按选项长度猜、最长并列时均匀选择，在新题上的理论命中率约 25.2%，全主测约 31.3%。试测时应单看旧题是否仍有长度提示，以及孩子点「看不懂」集中在哪些题。

**本轮家长反馈。** 已修改 15 道主测和 2 道诊断，每道的取舍记录在审题表「审阅意见」。card 与 bad 均保留在诊断题中。第 3、4 千词段用于定位较高识别量；psychology、bureaucracy、electron 的释义已简化，儿童试读时仍需观察是否因学科背景而选「看不懂」。

**审阅时优先看三组。** 请核对低龄孩子能否读懂 `while` 和 `than` 的选项；`interval` 的新义项是否适宜作为代表义；`electron`、`bureaucracy` 等题是否过度依赖学科背景。四个选项都应能单独读懂，仅一个符合给定语境。V2 自编义项拥有独立题目编号，已关联课程词头只表示拼写可对应。旧题的 `legacySource` 保存原义项 ID、修订号及角色，便于对照和识别重复暴露。

## 3. 独立口头复核

**成人单独保管复核表。** 每档 5 个，共 80 个。表内含单词、短语境、可接受的中文解释及部分认识示例。口头复核可让孩子**看到英文单词**，用中文解释、举例或做出恰当动作。先看词，遇到多义或需要确认所测义时再给文件中的英文语境。记录是否提示过语境。建议分次抽取，各次兼顾四个千词段，教师用释义留在成人端。[成人口头复核表](oral-holdout.csv)

记录「认识／部分认识／不认识」及孩子的原话。意思准确、可区分相近概念即可记认识。只说出上位类别，例如把 salmon 说成“鱼”，记部分认识。若给出另一个确切常用义，另行记录，再用中性语境确认所测义项。反馈答案放在本次复核结束后。

**抽词与隔离。** 使用阶段 ① 的冻结参考清单。先从候选中排除 V1 主测和诊断目标、已确认别名以及阶段 ① 标出的对应词族代表。口头复核另排除 V1 英文题面、选项中已经出现过的完整词。各档内按 SHA-256 值升序选前 5 个，随后才选择新主测。80 个留词都未作为完整英文词出现在本稿主测或诊断的目标词、语境或选项中。普通阅读、课堂接触及不同屈折形式的暴露无法从这些文件判定。

此规则让口头复核更独立，也改变了可抽词分布。在 4,000 个参考词中有 3,203 个进入口头候选，第 1 段 Q1 只有 47/250 个符合条件。成人复核适合发现选项提示、阅读困难和个人估值偏差；总体覆盖率与 36 题早停仍须用独立儿童样本及有代表性的对照卷评估。

固定排序串为 `rosie-v2-phase2-20261119/{用途}/{千词段}/{段内档}/{小写参考词头}`，用途取 `holdout` 或 `main`。主测按每档缺口顺序取词，只排除已预留词及上述 V1 目标集合。第 1、2 千词段 Q4 各取前 5 个新词。唯一的跳项为第 3 段 Q3 的咒骂词 `damn`，考虑低龄展示，以同档排序的下一候选 `provoke` 递补。阶段 ① 输入 reference-coverage.csv 的 SHA-256 为 `71cbb160e5f565960f6a501586e720739283a5e7a7349f8145948203a4e14c81`。

## 4. 给阶段 ③ 的容量边界

- **新答卷。** 每 12 题一段、主测最多 8 段。以首段每个千词段 3 题，之后每段同一千词段最多 7 题为可行配置。最集中时消耗 3＋7×7＝52 道，同时为一段均衡离线回退预留 3 道，共 55 道，低于最小千词段的 60 道。按档内已用数量轮转时，52 道最多占每档 13 道，回退段每档至多再占 1 道，低于最小档容量 15。每次发题仍需按实际未见词和已保留分支计算余额。
- **已有 V1 答卷的孩子。** 阶段 ③ 应按本人已展示过的词头过滤，并重新计算各档余量。即使去掉全部 119 个旧主测词，四个千词段仍有 29、30、41、36 道新题，足够跨段定位。剩余池不足以执行同样的集中抽题时，调整配额、报告较宽范围或提前结束。当前没有读取个人答卷，以上为题库容量推算。
- **自选诊断。** 29 个诊断目标中，act、character、garage、perform、repair 也出现在本版主测。即使这 5 个全被占用，新答卷仍有 24 个不同目标可用，恰好支持两段诊断。实际作答应扣除个人历史暴露，可用量不足时缩短或结束诊断。
- **发布边界。** 当前文件标记为 `editorial_draft`，用于审题与下一阶段接入。在线作答仍使用 V1 已发布题库。后续由 V2 服务端只发送当前题面，保留服务端判分，并把成人留题及答案隔离在学生端之外。
