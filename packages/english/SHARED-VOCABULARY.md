# 英语共享词库

KET、PET、FCE、厚海和其他英语词表走同一个词源。旧 `word_entries.id` 继续标识课程位置，试卷和媒体仍可使用旧引用。共享词头、义项、用法和拼写组使用自己的 UUID。正式试卷继续使用各自的答案快照。

## 迁移顺序

1. 保存 `word_entries`、PET 内容、学习记录和相关会话的备份。保留 `id`、`stage`、`unit`、`lesson`、`word` 和媒体字段，用于前后对账。用 `pnpm vocab:import --legacy-audit` 生成上线前候选表，审核大小写歧义和混合释义。
2. 应用 `20261118045218_shared_english_vocabulary`。它回填稳定词头并为旧释义创建未验证记录，已有 PET 结构化义项作为已审核来源。课程位置保留原 ID；同一位置重复的历史行仍可按 ID 查阅。
3. 应用 `20261118045414_shared_english_vocabulary_progress`。使用服务端 `backfill_vocabulary_practice` 按时间顺序回放旧的精确 PET 和自适应题目记录，每个区间最长 31 天。命中原会话和题目回执的记录可以重跑。无法确认目标的旧汇总保留在 `word_mastery`。当前线上版本的新增和编辑权限在应用切换前保留。新版发布并验证目录写入 RPC 后再收口旧写入。
4. 切到新版后，先检查词库首页、厚海每册课文词条、旧计划、PET 专项、正式试卷引用和音频。课程位置、旧统计与统一技能进度分别对账。出题和导入出现异常时，暂停相关写入，保留两套迁移和已经提交的回执用于续接。

## 审核和导入

`pnpm vocab:import --audit` 返回迁移后的主词头、课程位置、KET/PET 重合及待义项审核明细。使用应用已有的 Supabase 配置，通过只读查询生成结果。重合词头只提供审核线索。

`pnpm vocab:import --input /absolute/path/to/reviewed.json` 预览已整理的资料，列出待审、新词头、补义项、复用。FCE 的词、义项、课序和等级来自导入清单。每个待发布输入采用以下结构。

```json
[
  {
    "reviewed": true,
    "source": { "key": "fce-book", "revision": "1", "row": "p12-01", "rawHeadword": "degree" },
    "position": { "stage": "FCE", "unit": "FCE Unit 01", "lesson": "Lesson 01", "word": "degree" },
    "senses": [
      { "senseId": "<已审核义项 UUID>" },
      {
        "partOfSpeech": ["n."],
        "definitionEn": "amount or extent",
        "definitionZh": "程度",
        "cefr": "B2",
        "cefrSource": "English Vocabulary Profile"
      }
    ]
  }
]
```

- 用 `position.id` 把已审核义项附加到现有位置。混合释义可以绑定多条精细义项，历史中文和课程媒体保留。
- 选填 `senses[].usages`，每项有 `text`，可附带 `cefr` 和 `cefrSource`。有等级的项必须有依据。
- 选填 `spelling`，字段为 `key`、`preferred`、`answers`。同一词头的同一组键使用相同的可接受答案。只把对该位置的义项、语法形式有效的拼写放入组中。
- 后台每行的「编辑本课」修改课程字段。「共享义项」用于创建、修订或引用义项。编修释义范围时，新含义使用新的义项 ID。
- 人工确认试导后加 `--apply --creator <管理员 UUID>`。同一来源、版本和行的清单须保持内容一致，重跑会返回原位置 ID。调整内容时增加来源版本。批次按行提交，失败后从同一个文件重跑。

练习页的「按义项复习」优先安排当前范围内到期的已审核义项，再安排旧词复测和新义项。已有自适应课内阶段、Boss 和奖励仍由其计划及会话记录驱动。旧记录的跨词表复用需要精确到义项或等价词形组的作答证据。

## 分层抽样规则

`sampleVocabularyAssessment` 接收已审核的义项候选、词表范围和各等级配额。先按级别分层，再从高到低抽取各层尚未使用的词头，并在同一词头的本层义项中抽一个。配额不足按实际数量返回。已审核 CEFR 优先，其余按候选义项的最低适用词表保底级别。跨层去重按 `headwordId`，题干要有词性，必要时提供能明确义项的短句。工具返回各层覆盖和保底题数量。独立词汇量测评使用下文的版本化题库和计分规则。

## 手动验收

- `May` 和 `may` 应具有不同词头 ID。同课的普通大小写重复应归并，不同课仍可各自打开。
- 厚海 4A、5A 的课次、课文着色、例句、朗读音频和作业入口可用。练习词表总览去重，课内仍能打开对应卡片。
- `run` 的混合旧释义可以挂两个义项，无法定位的旧汇总继续出现在旧记录。检查有明确目标题目的历史回放。
- 在显示 `color` 和 `colour` 的位置分别输入另一变体，检查普通拼写、PET 拼写和听写的判分。检查听写与拼写各自拥有到期记录，并检查重试回执和跨日推进。
- 用一小份 FCE 清单试导复用、新增义项、新词头和歧义待审。验证同一批重跑、读写权限、课程 ID 以及已有会话的恢复。
- 给抽样函数供应固定随机序列和有 A2、B1 两义的 `degree`，核对高阶保留、同层补抽、单轮无重复、题库不足和保底覆盖。

## 词汇量测评

`/superpowers` 从 KET、PET、FCE 的共享词头出题。候选只收有等级依据和双语释义的已审核义项。
同一词头选最低等级的合格义项作为主测代表，已确认的拼写变体使用共享词头归并。其余义项可以作为诊断候选。
多义词使用能定位本题义项的短句。词数分母为该版本实际发布的唯一主测词头。正式发布前核对各层题库覆盖，
以及入选和排除的词头是否影响结果的代表性。

### 计分和试测

未提供校准文件的题库展示试测结果。每段随机交错呈现各层 3 道主测题。累计 48 道主测题且各层证据充足后，
答题中的卡尺可按已同步题目实时试算，并根据查看次数扩大抽样余量。交卷结果继续按完整主测段计算。
每层至少 12 道有效作答，且「看不懂选项」比例须低于 30%。任一层证据不足时暂缓显示总范围。
试测默认内部使用 `R − W/3`，主动点「不认识」记零并计入有效题数。「看不懂选项」在汇总区间里按完整可能得分范围处理。
汇总区间按题库各层词头数加权，并为多个查看节点调整抽样余量。儿童试测需要评估实际误差。
诊断题保存为 `item_role: diagnostic`，可在收尾时替换最多一个 12 题段，做完后沿用已有主测区间。
交卷后在 Word Screen 统一展示作答状态和当时的英中释义。

```sh
pnpm vocab:assessment --trial-export /tmp/rosie-assessment-trial.json --version <题库版本>
pnpm vocab:assessment --reviewed /tmp/rosie-assessment-review.json --calibration <校准文件> --apply
```

导出仅包含答卷标识、题位、角色、义项、等级、作答状态、选项位置和耗时，用于内部分析。
试测时比较同难度题目在不同段位置的答题表现，重点看 A1/A2 的释义可读性及最后约 30 题的错误、跳过和作答耗时变化。
用独立口头复核或长测比较原始得分和猜答校正的偏差，再用换卷复测评估稳定性和区间覆盖。
校准 JSON 字段为 `modelVersion: "stratified-v1"`、`method: "raw" | "formula"`、预览输出的 `itemsHash`、
`reference`（复核记录引用）和 `maxRelativeWidth`（正式区间的最大宽度占题库词头数的比例）。
达到 72 道主测题并通过覆盖、区间宽度条件时显示正式结果。48 题后基础层分数低或阅读困难时提示可提前交卷。

### 手动验收

- 将保存请求延迟 1–2 秒，连续点完一段。每次点选应立即推进题号、卡片和测过的单词。确认实时卡尺按已保存作答更新，交卷结果按完整段计算。
- 临时断网后答几题，再刷新同一个标签页。网络恢复后核对待同步答案按顺序提交。确认暂停和结果页等待作答同步。
- 答完一段后刷新页面或换设备，核对下一题、题序及进度。两台设备同时提交同一题时只应保存一次。
- 48 道后每层恰有 12 道主测题。在其中一层点一次「看不懂选项」，核对该层证据不足和总词数状态。
- 用 A1 低分和 A1 有至少 30%「看不懂选项」的答卷检查 48 题提前交卷入口。
- 完成一段诊断题后核对总词数范围未变化，导出中的角色正确。交卷前接口只提供当前段剩余的题面和作答回执。保存失败时保留待同步答案，交卷后检查错题释义和所选内容。
