# 增加课文跟读与听记

以 5A U3L2 为现有实现参考。先读 packages/english/AGENTS.md，通过课程 key 找出 reading-data 中的真实标题、小标题、段落、narrationCues 和听记配置。用阶段和录音内容确认课程；同一 U/L 在不同阶段可能重名。保留已有人工校准结果，除非新录音版本或用户要求需要替换。

## 音频反查与人工确认

标记前先独立转写实际录音，保留词级或短语时间戳，再与课文按顺序比对。统一大小写、引号和标点后查找漏词、多词与替换词；听记中的重复朗读合并比对。为每项差异列出文件或段号、时间、现有正文、听到的原话和建议修改，供用户逐项确认。只写入明确确认的正文更改，并同步听记英文和译文。无法独立转写或听清时说明未核实范围；强制对齐与波形匹配仅用于定位，不能证明字词相同。

按已核准的听记语义片段设置正文分界，全文高亮、句末耳机与听记抽屉共用同一套分段；一句拆成两个片段时分别绑定时间和锚点。

## 原文跟读

同时提供听记音频时，以核准的听记片段作为全文跟读的切分依据。每个练习片段对应的朗读内容都要在整课原音上单独定位起止时间；即使两个片段属于同一句，也分别设置正文分界、跟读高亮和听记锚点。听记文件内的重复和留白仅用于听记播放，不能把切片内的秒数直接写入全文 narrationCues。保留整课 MP3 连续播放，用时间区间完成逻辑切割。仅提供课文原音时，以完整句子作为全文跟读和听记的共同单位，按下述流程直接生成听记切片。用带时间戳的转写或强制对齐定位每个正文句的开始和结束（秒），结合录音复核缩写、数字、句内停顿和页码播报。标题、插播和静音不可错配给正文。按段写入 narrationCues，核对每段句数、时间范围与顺序，使播放、暂停和拖动时沿用现有高亮。只提供听记切片时可直接用已有课程文本完成听记映射；缺少同版本全文录音且没有既有时间表时，说明全文跟读尚缺的输入。

## 听记切片与对应

- **仅有课文原音**：对照正文与实际朗读划分完整句子，保留句内逗号、冒号、从句和自然停顿，注意人名缩写、小数点等不能当作句末。为每句在整课原音上标注起止时间，用同一组边界写入全文跟读时间表，并导出一条只朗读一遍的听记 MP3。切点放在语音外侧，保住首尾音，避开相邻句。朗读的标题、小标题可单独绑定相应锚点。为每段配正文锚点、英文和中文译文，按课程目录规范交付并接入听记抽屉。若播放器需要 singleRead，使用切片自身的时间坐标；需要重复时使用单段循环。

- **完整听记录音**：优先使用同源 LosslessCut 项目中已命名的人工边界，核对 mediaFileName、时长及边界处的语音。没有人工边界时，识别每次朗读的内容和起止时间；若来自同版全文录音，可在本地解码为单声道 PCM，按短时频谱特征匹配回全文时间轴，用连续匹配区间定位重复。不同讲者或匹配置信度低时改用转写及试听。静音检测仅辅助找落刀点。
- 将连续重复的同一句或同一分句连同中间的听写留白保存在**同一个 MP3**。在新内容开始前的停顿处分割，保留完整首尾音。标题、小标题也可单独成段。重复次数按录音实际情况处理。输出到独立课程目录，按录音顺序命名 U3L2-01.mp3 等；使用已有 FFmpeg（macOS 也可查找 LosslessCut 内置版本），按核准的起止区间批量导出，保留原文件。避免重新编码已满足要求的切片。
- **已切好的 MP3**：沿用用户分组，逐文件与原文匹配。编号用于排序，实际语音决定对应关系。检查漏号和重复号，已有编号与文件保持一致。对不确定的词句或边界单独标明，请用户确认后再落入映射。
- 每个片段记录文件编号、实际朗读的英文、自然中文译文和目标锚点。锚点沿用 title、heading-N、段号-句号（零起始）；多段可指向同一句。只朗读半句时展示该半句。同一片段跨多句时记录片段内各次朗读的时间轴以驱动切换；正文外的内容仅在抽屉展示。

## 页面与网盘

复用 listening-clips、PassageView、ListeningDrawer 和既有阅读详情页。给新课程注册听记清单，并同步扩展服务端 baiduReadingPath 的合法课程与片段范围；以实际文件编号生成 URL。维持句末耳机、当前句高亮、半屏抽屉、译文、单段循环和与全文朗读互斥的行为。不要把新课固定成 28 段；保留 U3L2 的现有路由兼容性。

整课目标为 /airosie/english/audio/{阶段}/{课号}.mp3，听记为 /airosie/english/audio/{阶段}/listening/{课号}/{课号}-{两位编号}.mp3。向用户交付可打开的本地切片目录或压缩包及目标路径。若当前任务允许上传且已有可写的共享课程网盘接口，核对账号、目录和文件，跳过已确认相同的文件，冲突时先询问；上传后核对远端数量、名称、大小及可取得的摘要。读取或播放权限不能证明具备上传权限。无可用上传接口时完成本地交付，并标明待上传。

交付前核对映射是否覆盖全部输入文件，抽听首尾、分句、标题和低置信片段。报告已处理的课号、片段数量、文件位置、网盘状态以及尚待核对的片段。遵守项目手动构建、测试约定。
